# Project Screenshots

Drop project screenshots here. Name them to match the project:

- `shocktest.png`   → ShockTest card
- `cogniscan.png`   → CogniScan card
- `shortlist.png`   → ShortList.ai card

Recommended: 16:9 or 4:3 ratio, at least 600px wide. JPG or PNG both work.
If a screenshot is missing for a project, the card just skips the image area.
